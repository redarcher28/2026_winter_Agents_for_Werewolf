# 神职策略

- **预言家（Seer）Alpha1.0**
- 验人目标策略：优先验高冲突/高带队位/对跳者；避免重复验；避免验明显边缘信息位。
- 报验策略：默认“白天报最新验人 + 给下一晚验人计划（警徽流/验人顺序）”。
- 对跳处理（最小版）：出现对跳时，输出一套固定结构：我是谁→我验了谁→为什么可信→今天票型建议。
- 投票策略：优先票“查杀”或与验人链矛盾者；若无查杀则跟随最可信带队位。
- **女巫（Witch）Alpha1.0用药原则：**
- 解药：优先救“高概率好人/带队位/预言家候选”，避免盲救；遵守是否可自救规则。
- 毒药：只在有强证据（查杀/高置信狼）时使用，避免早毒。
- 每晚最多一瓶：严格执行（并在 debug 记录为什么用/不用）。
- 信息表达（白天发言）：默认低调；但当需要带队时能给“我为什么不救/为什么毒”的可解释话术（不必明说身份，但要能圆逻辑）。
- 共同项（Seer+Witch）
- 状态/次数与回合重置：每晚一次、每局次数有限必须可靠；严格依赖 private_info（法官回执）。
- validate/fallback：任何非法目标/动作不允许/信息缺失都要稳妥兜底（no_op 或 no_potion）。
- 测试回放：至少用固定 phase 序列回放 2 天游程（seer_night→day_discussion→day_vote→witch_night→…），保证不会卡。



# 狼人策略

阶段覆盖扩展（最优先）

白天发言：增加“伪装发言/带节奏/表水/反咬”的 speech 输出（现在 Demo 只做夜刀）。

白天投票：增加 vote 决策（与夜刀目标形成一致叙事，避免“刀A投B”被抓逻辑）。

（可选）自爆/吞警徽规则：如果法官端支持 explode，把触发条件策略化（例如关键轮保队友、吞警徽、反查杀等）。

狼人协作（核心战力来源）

同伴信息利用：引入“分工”概念（冲锋狼/倒钩狼/深水狼），不同狼在白天的行为策略不同。

统一刀口：如果法官端要求“狼人统一意见”，需要一个“队内共识/优先级”机制（哪怕是最简单的：大家独立打分，取最高分目标）。

保护关键狼：对“已暴露/被查杀/被强推”的同伴给出护航策略（带偏投票、制造对立、转移矛盾）。

目标选择更“像人”从“好人概率最高”升级为“神职识别+屠边目标”：加入“神职雷达”（谁像预言家/女巫/猎人/警长），夜刀优先级不只看好人概率。

刀法策略库：首夜/中期/残局不同刀法（刀预言家候选、刀发言强势带队、刀警长、刀银水等）反制女巫：加入“骗药/逼毒/自刀诱导”的触发条件（若你们规则允许自刀/平安夜信息可推断用药）。

一致性与风控（Alpha 必须）

硬校验更全：目标存活、不可刀队友/自己、阶段允许、次数限制、超时兜底（你 Demo 有一部分，但要覆盖白天动作和更多规则）。

输出解释：debug.reason 建议结构化（例如 {"target_score": {...}, "top_features":[...], "plan":"deepwolf"}），方便复盘调参。



# 村民策略

信息处理能力升级（从模板 → 轻推理引擎）

投票证据融合：把 last_vote、投票绑定（跟票/冲票/弃票）、发言矛盾点纳入 camp_prob 更新（不只是读取概率，最好能“基于事件更新概率”）。

发言引用具体信息：发言不只模板，要能自动引用“本轮焦点”（上一轮投票、谁互踩、谁逻辑矛盾），哪怕是规则拼接也会显著更像人。

多目标排序：不仅给一个 target，内部保留 top-K 嫌疑列表（用于平票重投/临时改票）。

处理多预言家悍跳：当场上出现 2+ 预言家时，村民要有“站边规则”（先验逻辑一致性、对跳发言质量、投票流向、查验闭环）。

应对夜晚信息：night_reveal（平安夜/死人）对推理的影响（平安夜可能自刀骗药、死人是谁影响站边）。

稳定性与可控性

去随机化/可复现：Alpha 建议默认使用确定性选择（或固定 seed），方便回归测试与A/B对比。

self_player_id / allowed_actions 约束明确：你 Demo 最大隐患就是这些集成字段缺失会导致一直 no_op；Alpha 里要把“必填字段契约”写死，并在策略端做清晰的 debug 报错。
